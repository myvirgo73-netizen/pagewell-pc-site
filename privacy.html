Pagewell Reader · Windows

개인정보처리방침

이 방침은 Windows용 Pagewell Reader에 적용됩니다. 앱은 로컬 파일을 읽고 독서 기록을 관리하는 기능을 기본으로 제공하며, 이 기능을 사용하기 위해 Google에 로그인할 필요는 없습니다. 외부 서비스에 연결하거나 데이터를 동기화하는 것은 선택 사항입니다.

1. PC에 저장하는 정보

앱은 사용자가 고른 파일과 폴더를 열기 위해 파일 이름과 경로를 사용합니다. 읽던 위치, 독서 통계, 책갈피, 하이라이트, 메모와 첨부 사진, 앱 설정, 편집 초안 및 백업은 기본적으로 PC에 저장됩니다. 일반 독서 중 책이나 메모, 첨부 사진을 Pagewell 운영자 서버로 자동 전송하지 않습니다.

2. Google Drive 연결

Google 연결은 사용자가 해당 기능을 선택하고 Google 계정에서 권한을 승인한 경우에만 사용됩니다. 다음 두 기능은 서로 별도입니다.

원격 폴더 읽기 전용 연결

drive.readonly 권한으로 원격 폴더를 탐색할 때 파일과 폴더의 이름, 유형 등 목록 정보를 조회합니다. 사용자가 열기로 고른 파일은 PC로 내려받아 열며, 이 읽기 전용 기능으로 Drive의 원본을 수정하거나 삭제하지 않습니다.

선택 동기화

drive.appdata 권한으로 Google Drive 내 Pagewell 전용 공간에 접근합니다. 동기화를 켜면 사용자가 선택한 항목에 따라 책 이름과 식별 정보, 읽던 위치, 책갈피, 하이라이트, 메모 및 선택한 첨부 사진 등이 해당 공간으로 전송되고 다른 기기에서 불러와질 수 있습니다. 단순 원격 탐색만으로 동기화가 켜지지는 않습니다.

인증 정보와 연결 해제

연결을 유지하기 위한 Google 인증 토큰은 Windows의 보호 기능으로 암호화해 PC에 저장합니다. 앱에서 연결을 해제하면 해당 연결의 로컬 갱신 토큰을 지웁니다. Google 계정에서 부여한 권한을 철회하려면 Google 계정의 타사 연결 관리에서 Pagewell을 제거하세요. 이미 내려받은 파일이나 Drive에 저장된 동기화 자료는 연결 해제로 삭제되지 않습니다.

Pagewell이 Google API로 받은 정보를 사용하거나 다른 앱으로 전송하는 경우 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다.

3. 그 밖의 선택 기능

사용자가 등록한 WebDAV 등의 원격 서버 또는 외부 번역 서비스를 직접 사용하는 경우, 연결에 필요한 인증 정보나 사용자가 요청한 작업에 필요한 데이터가 해당 서비스로 전달됩니다. 예를 들어 외부 번역을 선택하면 번역할 글이 해당 제공업체로 전송됩니다. 각 외부 서비스의 보관 및 처리 방식은 그 서비스의 방침을 따릅니다.

4. 데이터 관리와 문의

PC에 저장된 독서 기록은 앱에서 해당 항목을 삭제하거나 로컬 앱 데이터를 정리해 관리할 수 있습니다. 내보낸 파일이나 원격 저장소에 저장한 자료는 해당 위치에서 별도로 삭제해야 합니다.
